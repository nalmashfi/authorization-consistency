# Supplementary Materials

*A Mathematical Model for Authorization Consistency in Persistent Multiagent Artificial Intelligence Systems*

For persistent multiagent systems, the supplements set out the formal basis for authorization consistency and the evidence used to assess it. In S2, the pseudocode specifies the checks that a protected action must pass before it can take effect. Each supplement uses its manuscript identifier. To connect a result with the definitions, measurements, or audit records that support it, the index identifies the relevant supplement as follows.
