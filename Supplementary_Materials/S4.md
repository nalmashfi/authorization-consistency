# S4. Lifecycle Stress Tests and Ablation Analysis

## S4.1 Targeted stress tests of the full model

For each lifecycle condition, the stress test records whether the full model prevents the specified authorization failure or preserves an action with surviving independent support. Preservation has a different interpretation from a violation. Among cases with surviving valid support, a higher rate means that more of the authorized actions retain access. For the other conditions, a lower rate means that fewer eligible trials produce the targeted violation. For each condition tested, the number of trials, the metric, and the result for the full model are as follows.

| Targeted condition | Trials | Metric | Full model |
|---|---:|---:|---:|
| Stale or false persistent authorization memory | 60,000 | ACVR | 0 |
| Checkpoint restoration after invalidation | 30,000 | ARR | 0 |
| Surviving independent authorization support | 80,000 | IPR | 1.000000 |
| Concurrent bounded authority use | 120,000 | CRR | 0 |
| Exact-support substitution | 50,000 | SSVR | 0 |
| Authorization change before protected commit | 80,000 | SACR | 0 |

## S4.2 Metric definitions

For the Authorization Consistency Violation Rate (ACVR), the denominator includes protected commit attempts that lack current authorization immediately before commit. The Independent Path Preservation Rate (IPR) requires a surviving valid support. After checkpoint restoration, the Authority Resurrection Rate (ARR) measures how often authority invalidated before restoration becomes executable again. For tests of concurrent bounded use, silent support substitution, and a change in authority before protected commit, the corresponding measures are the Concurrency Reuse Rate (CRR), Silent Support Substitution Violation Rate (SSVR), and Stale Authorization Commit Rate (SACR), respectively. For each rate, the eligible cases and the outcome counted among them are as follows.

$$
\mathrm{ACVR}=
\frac{N_{\text{protected commits with }AC(a,t_c^-)=0}}
{N_{\text{protected commit attempts with }AC(a,t_c^-)=0}}.
$$

$$
\mathrm{IPR}=
\frac{N_{\text{authorized actions preserved through surviving supports}}}
{N_{\text{cases with at least one surviving valid support}}}.
$$

$$
\mathrm{ARR}=
\frac{N_{\text{cases where invalid authority becomes executable after restoration}}}
{N_{\text{restore cases invalidated before restoration}}}.
$$

$$
\mathrm{CRR}=
\frac{N_{\text{concurrency trials with unauthorized bounded reuse}}}
{N_{\text{bounded concurrency trials}}}.
$$

$$
\mathrm{SSVR}=
\frac{N_{\text{executions with silent support substitution}}}
{N_{\text{targeted support substitution trials}}}.
$$

$$
\mathrm{SACR}=
\frac{N_{\text{stale authorization commits}}}
{N_{\text{precommit authorization change trials}}}.
$$

## S4.3 Component-targeted ablations

To test an individual component, the ablation compares the full model with the configuration that omits that component under the same targeted condition. For the protected commit boundary, the experiment uses a pre-dispatch interval of 5–500 ms and an authorization-change hazard of 0.85/s. The risk-layer ablation measures treatment after authorization. In that comparison, the Risk Treatment Rate (RTR) and Friction Introduction Rate (FIR) describe additional treatment among authorized actions. For each component removed, the trial count and the rates in the full and ablated configurations are as follows.

| Removed component | Targeted trials | Metric | Full model | Ablated |
|---|---:|---:|---:|---:|
| Memory revalidation | 60,000 | ACVR | 0 | 1.000000 |
| Memory revalidation under restore | 30,000 | ARR | 0 | 1.000000 |
| Independent-support tracking | 80,000 | IPR | 1.000000 | 0.320975 |
| Atomic reservation | 120,000 | CRR | 0 | 0.632750 |
| Exact-support revalidation | 50,000 | SSVR | 0 | 1.000000 |
| Protected commit boundary | 80,000 | SACR | 0 | 0.188488 |
| AI risk layer | 90,000 | RTR / FIR | 0.607302 / ≈0.2581 | 0 / 0 |

## S4.4 Interpretation

As shown in the ablation table, removing memory revalidation allowed stale authorization to be reused and invalidated authority to become executable after restoration. After selective revocation, the full model used independent-support tracking to preserve actions that retained a valid path. Atomic reservation prevented unauthorized reuse under concurrency. At protected commit, revalidation of the exact support prevented silent substitution, while the boundary prevented a stale commit after a change in trusted state. Thus, removing an enforcement component can change which actions reach protected execution, whereas removing the risk layer changes only the treatment of actions already authorized.
